# Art Space app - task description

Build an Art Space app that shows a gallery of artworks:
- Artwork wall: image of the artwork with a frame/shadow
- Artwork descriptor: title, artist and year
- Display controller: Previous and Next buttons
- Next shows the next artwork, after the last one goes back to the first
- Previous shows the previous artwork, from the first goes to the last
- Use state (remember + mutableStateOf) to store the current artwork
